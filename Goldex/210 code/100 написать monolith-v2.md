- Платформа и окружение
	- Основная целевая платформа — **Deno**:
	    - Сервис должен корректно запускаться в docker compose.
	    - Должен слушать порт из переменной окружения `PORT` (по умолчанию можно использовать `3000`).
	    - На этом порту должен быть доступен лёгкий HTTP-сервер (см. раздел **4.5**), реализованный только на стандартном модуле `http`.
	    - Должен корректно обрабатывать сигналы `SIGTERM` / `SIGINT` (graceful shutdown Moleculer-брокера).  
	- Запасной вариант — **Node.js**:
	    - Возможность локального запуска командой `npm run start` / `node dist/index.js` без привязки к конкретной PaaS.
	    - Никаких платформенно-специфичных зависимостей, мешающих запуску в обычном Node.js окружении.
	- Версия Node.js — **>= 24**.
